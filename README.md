# PyQt 翻译界面

这是一个支持中文、英语、韩语翻译的PyQt界面。

## 功能特点
- 选择目标语言（中文、英语、韩语）
- 输入文本框用于输入待翻译文本
- 输出文本框只读，显示翻译结果
- 提供独立的翻译接口供自定义实现

## 使用方法

### 1. 安装依赖
```bash
pip install PyQt5
```

### 2. 运行程序
```bash
python translator_gui.py
```

### 3. 实现翻译功能
在 `translator_gui.py` 文件中找到 `translate_text` 函数，替换其中的示例代码为你自己的翻译实现。

#### 接口参数说明：
- `input_text`: str - 需要翻译的输入文本
- `target_lang`: str - 目标语言代码 ('zh' = 中文, 'en' = 英语, 'ko' = 韩语)

#### 返回值：
- str - 翻译后的文本

## 界面布局
- 顶部：目标语言选择下拉框
- 中部：输入文本框（可编辑）
- 底部：输出文本框（只读）
- 右侧：翻译按钮

## 自定义扩展
你可以根据需要修改以下部分：
- 添加更多语言支持（修改 `self.target_language_combo` 的选项）
- 调整界面样式（修改 `setup_ui` 方法中的样式设置）
- 添加更多功能按钮
