# IReader UI 美化更新

## 🎨 新增UI特性

### 主题系统
- **Material Design 3** 完整实现
- **深色/浅色主题** 自动切换
- **自定义颜色方案** - 温暖的阅读体验
- **动态字体缩放** - 适应不同设备

### 书架界面
- **网格布局** - 现代化的书籍展示
- **书籍卡片** - 带有封面占位符和元数据
- **空状态设计** - 友好的引导提示
- **下拉刷新** - 流畅的交互体验

### 底部导航
- **三标签导航** - 书架、阅读器、设置
- **图标+文字** - 清晰的导航标识
- **选中状态高亮** - 直观的当前页面指示

### 组件库
- **BookItem** - 可复用的书籍卡片组件
- **BottomNavigation** - 自定义底部导航栏
- **LoadingState** - 加载和空状态处理

### 视觉设计
- **启动页** - 品牌化的应用启动体验
- **应用图标** - 简洁现代的IReader标志
- **间距系统** - 一致的布局间距
- **圆角设计** - 柔和的视觉效果
